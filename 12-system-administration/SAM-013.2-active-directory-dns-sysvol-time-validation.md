## Bidirectional DFSR SYSVOL Backlog Verification

**Purpose:** measure files awaiting replication from each sender relative to the receiving partner's SYSVOL version vector, without installing DFS management tools.

**Provenance:** no exact tested script was found in the searched repository documentation or automation files. The complete PowerShell 5.1 example below is **reconstructed**, not a verbatim archived script and not newly live-tested. The incident's verified result was **backlog count 0 in both directions, twice**; that result is not presented as execution of this reconstructed copy.

Verified provider method contracts in `root\MicrosoftDFS`, class `DfsrReplicatedFolderInfo`:

| Method | Inputs | Outputs |
|---|---|---|
| `GetVersionVector` | None | `ReturnValue`, `VersionVector` |
| `GetOutboundBacklogFileCount` | `VersionVector` string from receiver | `ReturnValue`, `BacklogFileCount`, `IdRecordIndex` |

Obtain the **receiver's** vector, then pass it to the **sender's** backlog method for the same replicated folder. Microsoft documents [GetVersionVector](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/dfsr/getversionvector-dfsrreplicatedfolderinfo) and [GetOutboundBacklogFileCount](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/dfsr/getoutboundbacklogfilecount-dfsrreplicatedfolderinfo). A missing instance, nonzero method return, or missing count is an error—not a zero backlog.

## ##Reconstructed reusable two-pass backlog script

```powershell
# Run in Windows PowerShell 5.1 using existing authorized Kerberos WinRM access.
# Read-only provider calls; no DFSR service actions or SYSVOL writes.
$ErrorActionPreference = 'Stop'
$dcNames = @('Techworks-DC01', 'DC-02')
$sessions = @{}
$results = @()
try {
    foreach ($dc in $dcNames) {
        $sessions[$dc] = New-PSSession -ComputerName $dc -ErrorAction Stop
    }

    for ($pass = 1; $pass -le 2; $pass++) {
        foreach ($sender in $dcNames) {
            $receiver = @($dcNames | Where-Object { $_ -ne $sender })[0]

            $receiverInfo = Invoke-Command -Session $sessions[$receiver] -ScriptBlock {
                $folders = @(Get-CimInstance -Namespace 'root\MicrosoftDFS' `
                    -ClassName 'DfsrReplicatedFolderInfo' -ErrorAction Stop |
                    Where-Object {
                        $_.ReplicationGroupName -eq 'Domain System Volume' -and
                        $_.ReplicatedFolderName -eq 'SYSVOL Share'
                    })
                if ($folders.Count -ne 1) { throw 'Expected exactly one SYSVOL instance.' }
                $folder = $folders[0]
                if ($folder.State -ne 4) { throw 'Receiver SYSVOL state is not Normal (4).' }
                $vector = Invoke-CimMethod -InputObject $folder `
                    -MethodName GetVersionVector -ErrorAction Stop
                if ($null -eq $vector.ReturnValue -or $vector.ReturnValue -ne 0 -or
                    [string]::IsNullOrWhiteSpace([string]$vector.VersionVector)) {
                    throw "Invalid receiver version vector; return=$($vector.ReturnValue)"
                }
                [pscustomobject]@{
                    VersionVector = [string]$vector.VersionVector
                    FolderGuid = [string]$folder.ReplicatedFolderGuid
                    GroupGuid = [string]$folder.ReplicationGroupGuid
                }
            } -ErrorAction Stop

            $backlog = Invoke-Command -Session $sessions[$sender] -ArgumentList @(
                $receiverInfo.VersionVector, $receiverInfo.FolderGuid, $receiverInfo.GroupGuid
            ) -ScriptBlock {
                param([string]$VersionVector, [string]$FolderGuid, [string]$GroupGuid)
                $folders = @(Get-CimInstance -Namespace 'root\MicrosoftDFS' `
                    -ClassName 'DfsrReplicatedFolderInfo' -ErrorAction Stop |
                    Where-Object {
                        $_.ReplicationGroupName -eq 'Domain System Volume' -and
                        $_.ReplicatedFolderName -eq 'SYSVOL Share'
                    })
                if ($folders.Count -ne 1) { throw 'Expected exactly one SYSVOL instance.' }
                $folder = $folders[0]
                if ($folder.State -ne 4) { throw 'Sender SYSVOL state is not Normal (4).' }
                if ([string]::IsNullOrWhiteSpace($FolderGuid) -or
                    [string]::IsNullOrWhiteSpace($GroupGuid) -or
                    ([guid]$folder.ReplicatedFolderGuid -ne [guid]$FolderGuid) -or
                    ([guid]$folder.ReplicationGroupGuid -ne [guid]$GroupGuid)) {
                    throw 'Sender and receiver SYSVOL identities do not match.'
                }
                $count = Invoke-CimMethod -InputObject $folder `
                    -MethodName GetOutboundBacklogFileCount `
                    -Arguments @{ VersionVector = $VersionVector } -ErrorAction Stop
                if ($null -eq $count.ReturnValue -or $count.ReturnValue -ne 0 -or
                    $null -eq $count.BacklogFileCount) {
                    throw "Backlog query failed; return=$($count.ReturnValue)"
                }
                [pscustomobject]@{
                    ReturnValue = $count.ReturnValue
                    BacklogFileCount = [uint32]$count.BacklogFileCount
                    IdRecordIndex = $count.IdRecordIndex
                }
            } -ErrorAction Stop

            $row = [pscustomobject]@{
                TimestampUtc = [datetime]::UtcNow.ToString('o')
                Pass = $pass
                Sender = $sender
                Receiver = $receiver
                BacklogFileCount = $backlog.BacklogFileCount
                ReturnValue = $backlog.ReturnValue
                IdRecordIndex = $backlog.IdRecordIndex
            }
            $results += $row
            $row # Emit each completed measurement; later failure cannot masquerade as success.
        }
    }
    if ($results.Count -ne 4) { throw 'Incomplete bidirectional two-pass measurement.' }
    if (@($results | Where-Object BacklogFileCount -ne 0).Count -gt 0) {
        Write-Warning 'Nonzero SYSVOL backlog observed; investigate trend and events.'
    }
}
finally {
    foreach ($session in $sessions.Values) {
        Remove-PSSession -Session $session -ErrorAction Continue
    }
}
```

**Expected:** four successful measurements, each with method return 0; an empty backlog reports count 0. Nonzero backlog is a measurement to investigate, not automatically proof of a permanent failure. On an exception, retain any earlier rows but classify the overall attempt as incomplete. Sessions are closed in `finally`.

**Observed supplied results, summarized rather than fabricated console output:**

| Measurement | Techworks-DC01 → DC-02 | DC-02 → Techworks-DC01 |
|---|---|---|
| First verification | 0 | 0 |
| Second verification | 0 | 0 |

Exact sample timestamps and spacing were not supplied; the reconstructed script takes consecutive fresh samples without inventing a historical interval. Zero backlog means no queued files were reported relative to those sampled vectors. It is not a byte-for-byte SYSVOL comparison, proof of future transport reliability, or an effective-access test.
