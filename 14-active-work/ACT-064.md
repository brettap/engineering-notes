deploy desktop with compatible monitor. Desktop deployment complete; separate QuickBooks admin-access issue unresolved.

## Issue/Symptoms

A new desktop could not display on the available VGA-only monitors.

## Environment

[organization]; new desktop requiring DisplayPort; four monitors tested; Microsoft account and remote QuickBooks server.

## Investigation/Troubleshooting

Only one of four monitors functioned. An attempted adapter chain failed to produce a signal.

## Root Cause

Display interface incompatibility and multiple nonfunctional existing monitors.

## Resolution

With recorded approval, purchased a compatible monitor, deployed the desktop and onboarded the user with Authenticator/phone registration.

## Verification

Verified login and access to the remote QuickBooks server. QuickBooks admin-account recovery remained unresolved.
