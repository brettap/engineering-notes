# ACT-092 — stop Windows 11 offer and pin Windows 10

**Evidence status:** Windows 10 feature pin completed; Windows Update and ESU remained unresolved.

**Source:** page 7; page ID {CC033587-BF6C-46BF-AE2F-38899B677773}

**Page date:** Monday, February 23, 2026 (page metadata; not assumed to be incident completion date).

## Synopsis

stop Windows 11 offer and pin Windows 10. Windows 10 feature pin completed; Windows Update and ESU remained unresolved.

## Issue/Symptoms

STATION-5-GETRPVS began downloading Windows 11 even though its tax software was incompatible. ESU installation also failed.

## Environment

STATION-5-GETRPVS; [organization]; Windows 10 Pro 22H2, build 19045.2965; source reports no domain/Entra/Intune join.

## Investigation/Troubleshooting

Source dated 02.26.26 lists stopped update services, cache rename/reset, servicing repair and product-key removal; Windows Update remained stuck checking for updates.

## Root Cause

Unwanted feature-update offer; why it appeared is not documented. Suspected update-agent/servicing inconsistency remains unconfirmed.

## Resolution

Stopped the Windows 11 upgrade, set ProductVersion=Windows 10, TargetReleaseVersion=1 and TargetReleaseVersionInfo=22H2 under HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate, restarted services and rebooted.

## Verification

The source states the Windows 11 feature update was no longer visible and Windows 10 22H2 pin succeeded. Windows Update scan still failed and ESU was not reinstalled in this dated entry.
