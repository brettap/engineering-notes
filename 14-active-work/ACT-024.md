# ACT-024 — reconnect OneDrive to migrated profile

## Synopsis

reconnect OneDrive to migrated profile. Resolved in the source write-up, supported by technician description.

## Issue/Symptoms

File Explorer could not open the OneDrive folder although OneDrive was syncing after an Azure AD migration.

## Environment

[organization]; Windows profile migrated by an unnamed third-party tool; OneDrive for Business.

## Investigation/Troubleshooting

Original username User.Name became UserName in the local profile. The old folder association no longer matched.

## Root Cause

The migration removed the period from the local username and left a stale OneDrive folder association.

## Resolution

Quit OneDrive, restarted it, and selected the correct OneDrive folder under the migrated profile.

## Verification

The source write-up reports File Explorer access restored and files syncing to the intended directory.

## Lessons/Operational Notes

Validate the actual profile and folder paths after migration. Password Boss and camera notes on the same page are incidental and are not additional incidents here.
